# NEVER install this into the application venv. The validated production model
# is a Cellpose 3 model: Cellpose >= 4.0.8 refuses to load it (ValueError), and
# 4.0.1-4.0.7 load it and silently produce garbage
# (build/maps/external-cellpose4.md). pyproject.toml pins cellpose>=3,<4 and
# the application refuses any other major version at run time.
#
# For the same reason never `pip install -e .` into .venv-cp4: pyproject's
# cellpose>=3,<4 would replace Cellpose 4. Put the checkout on the path
# instead; corridor.core.metrics needs numpy, and scipy.optimize (imported
# inside its matching function, for linear_sum_assignment), both below:
#
#   py -3.12 -m venv .venv-cp4
#   .venv-cp4\Scripts\python -m pip install -r requirements/cp4.txt
#   set PYTHONPATH=src
#
# This is `pip freeze --all` of the .venv-cp4 that exists (installed
# 2026-10-02, read the same day), less pip itself: the environment
# scripts/experiment_cpsam_zero_shot.py runs in, so a result from it can be
# reproduced. It was resolved by pip from Cellpose 4.2.1.1's open requirements,
# not from app.txt, so it is NOT the app environment with Cellpose swapped.
